1. ReShade 6.8.0.2155 (build with add-on support)
-------------------------------------------------
Files: plugins/lib/ReShade64.dll and plugins/lib/proxy/dxgi.dll (two copies of the same binary).
This is the unmodified crosire ReShade 6.8.0.2155 64-bit add-on build. Its original file name is ReShade64.dll.
The plugin loads the copy named dxgi.dll so that ReShade runs as a DXGI proxy. The copy named ReShade64.dll is a fallback.

5. Components NOT included (decisions of 2026-09-29)
----------------------------------------------------
  - renodx-dlss5 7.0.0-rc8 (DLSS 5 Neural Rendering add-on):
    - It is a closed-source community build, obtained from a mirror.
    - Neither the download nor the binary contains a licence or redistribution permission, so it is not
      redistributed.
    - It is optional: everything else works without it. README.md explains where it goes.
  - nvngx_dlssnr.dll (NVIDIA DLSS 5 Neural Rendering runtime 310.8):
    - Only renodx-dlss5 uses it.
    - It is not part of an NVIDIA SDK release obtained under a licence that permits redistribution, so it is not
      redistributed.
  - AMD FSR 3 upscaler: not in this release (the FidelityFX code above is frame generation only).
  - DLSS5-Feeder: not used. The package uses the native route (DLSS 5 runs inside tf2-dlss-sr's DLSS evaluate).
  - Northstar: required, not bundled.
