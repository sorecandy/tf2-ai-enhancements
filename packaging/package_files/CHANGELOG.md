# Changelog

## 1.0.0

- First Thunderstore release.
- Settings > Video > AI Enhancements page with these rows:
  - Upscaler: Off / DLSS.
  - Quality: DLAA / Quality / Balanced / Performance / Ultra Performance.
  - DLSS 5.
  - DLSS 5 Adjustments.
  - Frame Generation.
- NVIDIA DLSS Super Resolution upscaling (NVIDIA RTX GPUs).
- AMD FSR 3 frame generation on top of DLSS, on laptops with hybrid graphics (screen on the integrated GPU).
- Optional DLSS 5 Neural Rendering with user-supplied files (see README).
- A Northstar plugin loads the bundled ReShade (as a DXGI proxy) and the add-ons, so no manual ReShade install is needed. It steps aside if the game folder already has a ReShade.
- AMD FSR 3 upscaling is not included in this release.
